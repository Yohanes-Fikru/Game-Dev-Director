# New Project Onboarding

Use this route when the project is an idea or has little implementation evidence.

## Establish only what changes the next move

Infer what you can, then ask at most three questions about the largest unknowns:

- player fantasy and the experience worth protecting;
- target player, platform, input, and session shape;
- team, available skills, deadline, budget, and non-negotiable constraints;
- core loop and the riskiest belief behind it;
- references, differentiators, and unacceptable outcomes.

Challenge bundles of features by asking which one is essential if the rest are
cut. Treat undecided details as unknowns, not blockers.

## Exit onboarding

Stop questioning when you can state:

1. a one-sentence game promise;
2. the inferred scale profile and constraints;
3. the riskiest hypothesis;
4. the smallest playable experiment;
5. observable success or kill signals.

Create only the state files needed to preserve those answers. Then move into the
iteration engine and produce work.
